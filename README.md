# yust.dev

The source for [yust.dev](https://www.yust.dev), Yousef Mohammed Salah's portfolio for AI security, competitive programming, full-stack products, hackathons, certificates, and engineering stories.

## Stack

- React 19 and strict TypeScript
- TanStack Start and TanStack Router
- Vite+ and Rolldown
- Tailwind CSS 4
- Nitro server output on Vercel
- Framer Motion for route-scoped interaction
- Satori and Resvg for Open Graph artwork

The application is static-first. Portfolio content lives in the repository rather than a CMS or database. The private `/token-usage` route is the exception: a TanStack server function fetches usage data from an external API.

## Commands

Use the Vite+ CLI rather than invoking pnpm, Vite, Vitest, Oxlint, or Oxfmt directly.

```bash
vp install
vp dev
vp check
vp test
vp build
vp preview
```

Additional project tasks:

```bash
vp run seo:generate  # rebuild sitemap.xml and rss.xml from source content
vp run og:generate   # rebuild static SEO files and Open Graph artwork
vp run seo:audit     # audit a running production build at localhost:3000
```

`vp build` validates the application bundle. The package-level deployment build also regenerates SEO and Open Graph assets before compiling.

## Structure

```text
src/
  components/
    about/             Home-page sections
    projects/          Project catalog, cards, videos, and lazy drawers
    token-usage/       Private usage visualization
  lib/
    hooks/             Browser-safe reusable hooks
    seo.ts             Canonical metadata and JSON-LD builders
  routes/              TanStack file-based routes
scripts/
  generate-static-seo.mjs  Sitemap and RSS generator
  generate-og-*.mjs        Satori/Resvg social-card generators
  seo-audit.mjs            Rendered-site SEO audit
public/
  certi/               Certificate images
  static/              Images, icons, and social cards
  videos/              Project showcase videos
```

`src/routeTree.gen.ts` is generated by TanStack Router and must not be edited manually.

## Content workflow

- Add or update projects in `src/components/projects/ProjectsData.ts`.
- Add the corresponding narrative drawer under `src/components/projects/drawers/` when needed.
- Add blog posts in `src/routes/_main/blog.index.tsx`.
- Add certificates in `src/routes/_main/certificates.tsx`.
- Run `vp run seo:generate` after changing project or blog slugs.
- Run `vp run og:generate` when social-card content changes.

The content-sync test fails if a project or blog URL is missing from the sitemap or RSS feed.

## Quality gate

Before committing:

```bash
vp check
vp test
vp build
```

For a rendered SEO check, start the production server on port 3000 and run `vp run seo:audit` in another terminal.

## Deployment

Vercel serves the Nitro output. `vercel.json` defines legacy redirects, security headers, content types, and long-lived immutable caching for versioned static media.
